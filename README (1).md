# Учёт стройматериалов на складе

Программа для учёта стройматериалов на складе строительной компании: приход материалов от поставщиков, выдача на объекты и контроль остатков. Лабораторная работа: реализация графического пользовательского интерфейса и интеграция базы данных.

## Возможности

- **Вкладка «Склад»** — таблица материалов с остатками, добавление и удаление позиций.
- **Вкладка «Приход и расход»** — проведение операций (завоз от поставщика или выдача на объект) и журнал последних операций.
- **Вкладка «Отчёт»** — сводка по остаткам, закончившиеся материалы подсвечиваются красным.

## Технологии

- Python 3
- **PyQt6** — графический интерфейс (три вкладки, таблицы, формы, диалоги подтверждения)
- **SQLite** — встроенная база данных, не требует установки сервера

## Структура базы данных

База создаётся автоматически при первом запуске (`sklad.db`), вместе с демо-данными.

- **materials** — справочник материалов: `id`, `name` (уникальное наименование), `unit` (единица измерения), `quantity` (текущий остаток).
- **operations** — журнал операций: `id`, `material_id` (внешний ключ на materials), `op_type` (приход/расход), `amount` (количество), `comment`, `created` (дата и время).

## Запуск

```
pip install -r requirements.txt
python sklad.py
```

## Сборка исполняемого файла (exe)

Собрать самостоятельный exe можно с помощью PyInstaller:

```
pip install pyinstaller
python -m PyInstaller --onefile --noconsole sklad.py
```

- `--onefile` — все файлы упаковываются в один exe;
- `--noconsole` — окно терминала при запуске не открывается.

Готовый файл появится в папке `dist`. Python на компьютере, где запускается exe, не нужен. База данных `sklad.db` создаётся рядом с программой при первом запуске. Размер файла около 60-80 МБ — это нормально, вместе с приложением упаковываются библиотеки Qt. Некоторые антивирусы могут давать ложное срабатывание на exe, собранные PyInstaller, — это известная особенность.

## Прецеденты использования

1. **Добавить материал на склад** — кладовщик добавляет новую позицию с наименованием и единицей измерения; система проверяет заполнение полей и уникальность наименования.
2. **Провести операцию прихода/расхода** — кладовщик выбирает материал, тип операции и количество; при расходе система проверяет достаточность остатка и записывает операцию в журнал.
3. **Сформировать отчёт об остатках** — пользователь открывает вкладку отчёта и видит все материалы с остатками и статусом достаточности.
