# Учёт стройматериалов на складе

Учебная программа (контрольная работа): автоматизация учёта прихода и расхода
стройматериалов на складе строительной организации.

## Возможности

- Ведение справочника материалов (добавление и удаление).
- Проведение операций **прихода** (завоз от поставщика) и **расхода**
  (выдача на объект) с проверкой достаточности остатка.
- Журнал последних операций с датой, материалом и комментарием.
- Отчёт об остатках: закончившиеся материалы подсвечиваются красным.

## Технологии

- Python 3
- PyQt6 — графический пользовательский интерфейс
- SQLite — встроенная база данных (сервер не требуется)

## Запуск

```
pip install -r requirements.txt
python sklad.py
```

Файл базы данных `sklad.db` создаётся автоматически при первом запуске
и наполняется демо-данными (8 материалов, 11 операций).

## Структура базы данных

- **materials** — справочник материалов: `id`, `name` (уникальное название),
  `unit` (единица измерения), `quantity` (текущий остаток).
- **operations** — журнал операций: `id`, `material_id` (внешний ключ),
  `op_type` (приход/расход), `amount` (количество), `comment`, `created`
  (дата и время).

## Прецеденты использования

1. Добавить материал на склад.
2. Провести операцию прихода/расхода (с проверкой остатка при расходе).
3. Сформировать отчёт об остатках.
